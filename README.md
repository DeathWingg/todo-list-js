# ✅ Lista de Tarefas (To-Do List)

Projeto simples de lista de tarefas desenvolvido para praticar HTML, CSS e JavaScript.

## 🚀 Acesse o projeto rodando
👉 [Clique aqui para ver o projeto funcionando](https://deathwingg.github.io/todo-list-js/)

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3 (Flexbox e Dark Mode)
- JavaScript (Manipulação de DOM e LocalStorage)

## ⚙️ Funcionalidades
- Adicionar tarefas
- Marcar tarefas como concluídas (clicando no texto)
- Deletar tarefas (botão X vermelho)
